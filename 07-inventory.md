# 07 — Inventario

## Tipos

### Uso único
Una unidad se consume por completo.

### Multiuso reutilizable
No se mide remanente exacto.

Se controla:
- cerrados,
- abiertos,
- agotados,
- descartados.

## Prioridad

Si hay un frasco abierto, debe proponerse primero.

Si existen varios abiertos:
priorizar el más antiguo.

## Registro en procedimiento

Para multiuso:
- usar abierto,
- abrir nuevo,
- al finalizar:
  - sigue abierto,
  - agotado,
  - descartado.

## Cantidad estándar

Un Servicio sí puede tener cantidades económicas estándar:

Ejemplo:
Xiomin = 0.25 unidad

Esto sirve para costo estándar y margen, no para decir cuánto queda físicamente.

## Merma

Si un contenedor se descarta antes de generar el aprovechamiento económico estándar previsto, registrar merma estimada.

Motivos:
- vencimiento,
- tiempo abierto,
- contaminación,
- daño,
- pérdida,
- uso extraordinario,
- canje/cortesía,
- ajuste,
- otro.
