# 09 — User Journeys

## A. Crear cliente y procedimiento
1. Crear cliente.
2. Cliente aparece automáticamente en selector.
3. Crear procedimiento.
4. Seleccionar Servicio.
5. Precargar precio, productos estándar y remarketing.
6. Confirmar productos realmente usados.
7. Resolver inventario abierto/cerrado.
8. Resolver estado de pago.
9. Guardar.
10. Actualizar historial, inventario, CRM y finanzas.

## B. Pago inmediato
1. Procedimiento realizado.
2. Registrar pago ahora.
3. Elegir moneda.
4. Elegir método.
5. Elegir dónde entró el dinero.
6. Calcular 70/30.
7. Calcular comisión si corresponde a Rodolfo.
8. Extraer IVA.
9. Calcular margen.
10. Dejar movimiento pendiente de conciliación.

## C. Pago pendiente
1. Procedimiento queda Pago pendiente.
2. Aparece en Finanzas.
3. Registrar pago.
4. Estado cambia a Pagado.
5. Generar conciliación/margen.

## D. Pago adelantado
1. Registrar pago.
2. Crear/vincular procedimiento futuro.
3. Procedimiento: Pendiente.
4. Pago: Pagado.
5. Al realizar, registrar inventario sin volver a cobrar.

## E. Registrar compra
1. Seleccionar producto maestro.
2. Cantidad.
3. Precio real.
4. Vencimiento.
5. Estado de factura.
6. Actualizar inventario.
7. Guardar histórico de precio.
8. Si pendiente, crear cuenta por pagar.
9. Crear tarea CRM si tiene vencimiento.

## F. Pagar cuenta
1. Abrir cuenta pendiente.
2. Registrar pago.
3. Actualizar saldo.
4. Si saldo 0 → Pagada.
5. Registrar histórico.
6. Completar tarea vinculada.

## G. Conciliar semana
1. Calcular Rodolfo → Clínica.
2. Calcular Clínica → Rodolfo.
3. Registrar pago real de cada obligación.
4. Ambas deben quedar Pagadas.
5. Habilitar Conciliar semana.
6. Cerrar período.
7. Los movimientos pasan a Conciliados.
