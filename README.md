# Dr. Rodolfo Cabezas — WebApp de Gestión

Repositorio de referencia para el desarrollo de una webapp de gestión para la práctica independiente del Dr. Rodolfo Cabezas dentro de una clínica estética.

## Objetivo

Centralizar y conectar:

- Clientes
- Servicios
- Procedimientos
- Inventario
- Pagos de pacientes
- Conciliación 70/30 con la clínica
- Gastos y cuentas por pagar
- CRM y tareas
- Remarketing
- Usuarios y permisos
- Métricas de margen, comisiones, IVA y merma

La app **no reemplaza** SICU/SICO, FotoDoc ni la agenda general de la clínica. Funciona como un sistema de control cruzado y gestión propia de la práctica de Rodolfo.
