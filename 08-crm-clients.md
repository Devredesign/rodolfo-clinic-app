# 08 — CRM y Clientes

## Niveles
Bronze / Silver / Gold / Platinum

Inicialmente basados en cantidad de pagos. Deben quedar configurables.

## Remarketing

Cada Servicio puede tener una regla:
ej. Botox → 4 meses

Cuando se cumple el período:
- cliente aparece en remarketing,
- se crea tarea sugerida,
- botón para abrir WhatsApp,
- no enviar automáticamente.

## CRM

Tipos de tareas:
- remarketing,
- seguimiento,
- cobro,
- pago,
- pedido,
- consentimiento,
- protocolo,
- administrativo.

Estados:
- Pendiente
- Realizada
- Archivada

Historial archivado con filtros de fecha.

## Automatizaciones internas

- Servicio realizado → programar remarketing.
- Stock bajo → tarea de pedido.
- Cuenta/gasto con vencimiento → tarea de pago.
- Pago registrado → completar tarea financiera vinculada.
- Protocolo con sesión pendiente → tarea de seguimiento.
