# 05 — Usuarios y permisos

## Admin — Rodolfo

Puede:
- ver todo,
- crear/editar usuarios,
- crear/editar/desactivar servicios,
- cambiar precios,
- cambiar costos,
- editar tipo de cambio,
- crear/editar productos,
- ver finanzas,
- registrar/editar/anular pagos,
- conciliar,
- editar categorías de gasto,
- corregir históricos con auditoría.

## Asistente — Andrea

Puede:
- crear clientes,
- editar datos operativos permitidos,
- registrar procedimientos,
- registrar productos usados,
- registrar compras recibidas,
- registrar pagos de pacientes,
- crear tareas,
- completar tareas,
- gestionar consentimientos cuando exista módulo.

No puede:
- cambiar precios maestros,
- cambiar costos maestros,
- modificar reglas 70/30,
- ver métricas financieras sensibles,
- administrar usuarios,
- borrar/anular movimientos sensibles salvo permiso explícito.

## Auditoría

Guardar:
- quién creó,
- quién editó,
- cuándo,
- valor anterior,
- valor nuevo,
- motivo si aplica.
