Política de Privacidad

Esta Política de Privacidad describe cómo la aplicación de gestión clínica del Dr. Rodolfo Cabezas ("la Aplicación") accede, utiliza, almacena y protege la información necesaria para prestar sus funciones administrativas y financieras.

1. Datos que procesa la aplicación

La Aplicación puede procesar información administrativa introducida por usuarios autorizados, incluyendo datos de pacientes, procedimientos, pagos, gastos, inventario y tareas. Cuando el usuario autoriza la integración con Gmail, la Aplicación puede acceder a mensajes, encabezados, cuerpo del correo y adjuntos de la cuenta autorizada en la medida necesaria para la función de bandeja financiera.

2. Uso de datos de Google

El acceso a Gmail se realiza únicamente para leer correos financieros de la cuenta autorizada, detectar documentos o movimientos relevantes, extraer datos como fecha, monto, moneda, proveedor o referencia, y presentarlos al usuario para revisión. La Aplicación utiliza el alcance de Gmail de solo lectura y no utiliza esta integración para enviar, modificar o eliminar mensajes.

El uso y transferencia de información recibida de las APIs de Google se realiza de conformidad con la Google API Services User Data Policy, incluidos sus requisitos de Limited Use.

3. Almacenamiento y proveedores de servicio

La Aplicación utiliza proveedores de infraestructura y procesamiento necesarios para operar el servicio. Esto puede incluir servicios de base de datos y almacenamiento en la nube, hosting de la aplicación y servicios de inteligencia artificial utilizados para extraer información de determinados correos o adjuntos. Estos proveedores reciben únicamente la información necesaria para prestar la función correspondiente.

Los correos y documentos financieros procesados pueden almacenarse de forma privada dentro de la infraestructura de la Aplicación para mantener evidencia y trazabilidad de los movimientos revisados.

4. Inteligencia artificial

Cuando un documento no puede interpretarse de forma determinística, parte del contenido del correo o de sus adjuntos puede ser procesada por un proveedor de inteligencia artificial con el único propósito de extraer y estructurar información financiera para la funcionalidad visible de la Aplicación. Las decisiones financieras finales requieren revisión humana.

5. Compartición y venta de datos

La Aplicación no vende datos personales ni datos obtenidos mediante las APIs de Google, no los utiliza para publicidad y no los transfiere a corredores de datos o plataformas publicitarias. La información puede ser procesada por proveedores de servicio únicamente cuando sea necesario para operar y proteger la Aplicación, o cuando exista una obligación legal aplicable.

6. Acceso humano

El acceso humano a información almacenada se limita a usuarios autorizados de la organización y, cuando sea estrictamente necesario, a tareas de soporte, seguridad o cumplimiento aplicables. Los permisos de la Aplicación están diseñados para restringir el acceso a la organización correspondiente.

7. Seguridad

Se aplican controles técnicos de autenticación, autorización y acceso restringido a los registros y documentos almacenados. No obstante, ningún sistema puede garantizar seguridad absoluta.

8. Retención y eliminación

La información se conserva mientras sea necesaria para las funciones administrativas, financieras, de trazabilidad o cumplimiento de la práctica. El titular autorizado puede solicitar la revisión o eliminación de datos cuando corresponda y sea compatible con obligaciones legales o de conservación aplicables.

9. Cambios a esta política

Esta política puede actualizarse para reflejar cambios en la Aplicación, sus proveedores o sus prácticas de datos. La fecha de la última actualización se mostrará al inicio de esta página.

10. Contacto

Para consultas relacionadas con privacidad o con el uso de datos en la Aplicación, puede escribirse a finanzasrodolfocabezas@gmail.com.
